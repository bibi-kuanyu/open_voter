# open_voter — 台灣選舉政見履約追蹤與查詢平台

## 專案定位與目標

open_voter 是一個專注於台灣選舉的政見履約追蹤與查詢平台。我們的核心目標是建立一個以候選人政見為核心的指標性追蹤系統。透過將候選人提出的政見轉化為關鍵績效指標 (KPI)，並結合新聞報導、事實查核資料，對照候選人實際的執行情況，以透明化的方式呈現長期追蹤的結果。

此平台旨在打破資訊隔閡，讓選民能夠全面了解候選人及其承諾的履行狀況。

### 核心目標

*   **政見履約追蹤：** 以候選人政見為核心，追蹤其完成度。
*   **KPI 導向：** 將政見轉化為可衡量的 KPI 進行追蹤。
*   **資料整合與驗證：** 結合新聞、事實查核等資料，驗證政見執行情形。
*   **長期透明化呈現：** 提供長期追蹤報告，呈現候選人的履約紀錄。

### 長期拓展規劃

*   **多年度支援：** 支援不同年份的選舉資料（如 2024、2026、未來年度），建構延續性的資料庫。
*   **多元選舉類型：** 不以單一選舉入口，逐步擴展至總統、立委、地方公職等多種類型的選舉。

## 資料來源與內容設計

### 主要資料來源

*   **READr (政見查詢平台)：** 作為政見資料的初始擷取點，確保資料的權威性與完整性。

### 輔助來源與驗證

*   **可信新聞媒體：** 廣泛蒐集報導，了解政見的討論熱度與實際進展。
*   **事實查核中心：** 引用專業的事實查核報告，核實相關資訊的真實性。
*   **政府公開資料：** 引用官方發布的政策、預算、執行報告等，作為客觀依據。

### 資料欄位設計（初步，待實作補充）

*   **候選人基本資訊：**
    *   姓名
    *   政黨
    *   選區/地區
*   **政見列表：**
    *   政見標題
    *   政見摘要
    *   政見長描述
*   **政見 KPI 狀態：**
    *   待追蹤 (To Track)
    *   進行中 (In Progress)
    *   已完成 (Completed)
    *   未達成 (Not Achieved)
    *   已取消/變更 (Cancelled/Modified)
*   **資料來源與連結：**
    *   新聞報導連結
    *   事實查核報告連結
    *   官方資料連結
*   **候選人狀態：**
    *   當選
    *   未當選
    *(所有候選人資訊與政見均可納入追蹤，無論當選與否，以體現全面的政治參與評估)*
