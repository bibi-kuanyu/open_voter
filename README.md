# open_voter — 台灣選舉政見履約追蹤與查詢平台

## 專案定位與目標

open_voter 是一個專注於台灣選舉的政見履約追蹤與查詢平台。我們的核心目標是建立一個以候選人政見為核心的指標性追蹤系統。透過將候選人提出的政見轉化為關鍵績效指標 (KPI)，並結合新聞報導、事實查核資料，對照候選人實際的執行情況，以透明化的方式呈現長期追蹤的結果。

此平台旨在打破資訊隔閡，讓選民能夠全面了解候選人及其承諾的履行狀況。

### 核心目標

*   **政見履約追蹤：** 以候選人政見為核心，追蹤其完成度。
*   **KPI 導向：** 將政見轉化為可衡量的 KPI 進行追蹤。
*   **資料整合與驗證：** 結合新聞、事實查核等資料，驗證政見執行情形。
*   **長期透明化呈現：** 提供長期追蹤報告，呈現候選人的履約紀錄。

### 長期拓展規劃

*   **多年度支援：** 支援不同年份的選舉資料（如 2024、2026、未來年度），建構延續性的資料庫。
*   **多元選舉類型：** 不以單一選舉入口，逐步擴展至總統、立委、地方公職等多種類型的選舉。

## 🔧 GitHub Pages 部署注意事項

### 問題：404 連結錯誤

**原因：** GitHub Pages 部署在 repository 子目徑下，URL 結構為：
```
https://[username].github.io/open_voter/...
```

若 HTML 中使用 `href="/pages/2024.html"`，瀏覽器會解析為：
```
https://[username].github.io/pages/2024.html  ❌ 404
```

正確應為：
```
https://[username].github.io/open_voter/pages/2024.html  ✅
```

### 解法

**所有路徑前綴必須加上 `/open_voter/`**

| 錯誤写法 | 正確寫法 |
|---------|----------|
| `href="/"` | `href="/open_voter/"` |
| `href="/pages/2024.html"` | `href="/open_voter/pages/2024.html"` |
| `href="/#years"` | `href="/open_voter/#years"` |

### 未來避免方式

1. **固定前綴**：專案內所有 HTML 連結統一使用 `/open_voter/` 前綴
2. **本地測試**：使用 `python3 -m http.server 8080` 在本機測試，確認路徑正確
3. **部署前檢查**：上傳前確認所有 `href` 和 `src` 屬性
4. **或使用相對路徑**：在同目錄下可使用 `href="pages/2024.html"`（不用開頭的 `/`）

## 📊 參考網站分析：whoareyou.readr.tw

### 該網站優點

1. **豐富的政見資料**：每個候選人多達數十至上百條政見
2. **分類系統完善**：38 種政見分類（能源、教育、社會福利、醫療、國防等）
3. **事實查核整合**：每條政見有「背景事實查核」區塊
4. **專家觀點**：學者或專業人士對政見的分析
5. **横向比較**：同一分類下比較不同候選人的政見差異
6. **進度追蹤**：區域立委有「補坑進度」追蹤
7. **協作機制**：開放公民協作編輯政見資料

### 我們的差異化方向

| 面向 | READr 網站 | Open Voter（我們） |
|------|-----------|-------------------|
| **核心定位** | 政見資料庫 + 事實查核 | 政見履約率 KPI 追蹤 |
| **KPI 追蹤** | 無 | ✅ 核心功能 |
| **進度條視覺化** | 無 | ✅ 達成率進度條 |
| **時間軸呈現** | 較少 | 可強化候選人政見 vs 執政成果對照 |
| **政見分類** | 38 種（細） | 可簡化為 8-10 大類（易懂） |
| **新聞整合** | 事實查核为主 | 可整合更多新聞報導與進展 |
| ** UI 風格** | 資料導向、偏學術 | 親和、易讀、視覺化優先 |
